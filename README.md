== Installation ==

1. Загрузите папку `html-site-map-generator` в директорию `/wp-content/plugins/`
2. Активируйте плагин через меню 'Плагины' в WordPress
3. Перейдите в Настройки → Карта сайта для настройки
4. Файл sitemap.xml автоматически создается в корне сайта
5. Используйте шорткод `[html_sitemap]` на любой странице или записи

== Usage ==

= HTML Карта сайта =
Для вставки HTML карты сайта на страницу используйте шорткод:
`[html_sitemap]`

Все настройки управляются через админку WordPress. Параметры в шорткоде не поддерживаются.

= XML Карта сайта =
XML карта сайта создается как реальный файл и доступна по адресу:
`https://ваш-сайт.ru/sitemap.xml`

**Автоматическое обновление:**
- При создании/редактировании/удалении записей и страниц
- При создании/редактировании/удалении категорий
- С отложением 30 секунд для избежания частых обновлений

**Ручное управление:**
- Кнопка "Обновить XML карту" в настройках плагина
- Кнопка "Удалить XML файл" для полного удаления

= Настройка категорий для записей =
В настройках плагина можно указать ID категорий, из которых показывать записи:
- При указании одной категории - заголовок раздела меняется на название категории
- При указании нескольких категорий - показываются их названия через запятую
- Приоритет над другими настройками включения/исключения

== Frequently Asked Questions ==

= Как добавить карту сайта на свой сайт? =
Используйте шорткод `[html_sitemap]` на любой странице или записи. Рекомендуем создать отдельную страницу "Карта сайта".

= Где найти XML карту сайта? =
XML карта доступна по адресу `https://ваш-сайт.ru/sitemap.xml`. Файл создается автоматически в корне сайта.

= Как работает автоматическое обновление XML? =
При любом изменении контента (создание, редактирование, удаление записей, страниц, категорий) плагин автоматически обновляет файл sitemap.xml с задержкой 30 секунд.

= Можно ли отключить автоматическое обновление? =
Да! В настройках плагина снимите галочку "Автоматически обновлять XML карту при изменении контента".

= Что делать если файл sitemap.xml не создается? =
1. Проверьте права на запись в корневую директорию WordPress
2. Нажмите кнопку "Обновить XML карту" в настройках плагина
3. Проверьте логи ошибок WordPress

= Как исключить определенные страницы из карты сайта? =
В настройках плагина в разделе "Управление по ID" укажите ID страниц через запятую в поле "Исключить записи/страницы".

= Почему время обновления показывает неправильно? =
Время отображается в часовом поясе, установленном в настройках WordPress. Проверьте настройки часового пояса в Настройки → Общие.
