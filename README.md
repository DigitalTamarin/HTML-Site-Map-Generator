== Description ==

HTML & XML Site Map Generator - это мощный плагин для создания красивых структурированных HTML карт сайта для пользователей и XML карт для поисковых систем. Все настройки управляются через удобную панель в админке WordPress.

= Основные возможности =
* 📊 **HTML карта сайта** - красивая структурированная карта для пользователей
* 🔍 **XML карта сайта** - автоматическая генерация для поисковых систем
* ⚙️ **Полные настройки в админке** - никаких параметров в шорткодах
* 🎯 **Гибкое управление контентом** - включение/исключение по типам и ID
* 📱 **Адаптивный дизайн** - отлично выглядит на всех устройствах
* 🔧 **Кастомизация CSS** - легкая настройка стилей

= English Version =
Advanced HTML and XML sitemap generator with full admin settings for WordPress. Creates beautiful sitemaps for users and search engines.

== Installation ==

1. Загрузите папку `html-site-map-generator` в директорию `/wp-content/plugins/`
2. Активируйте плагин через меню 'Плагины' в WordPress
3. Перейдите в Настройки → Карта сайта для настройки
4. Используйте шорткод `[html_sitemap]` на любой странице или записи

== Usage ==

= HTML Карта сайта =
Для вставки HTML карты сайта на страницу используйте шорткод:
`[html_sitemap]`

Все настройки управляются через админку WordPress. Параметры в шорткоде не поддерживаются.

= XML Карта сайта =
XML карта сайта автоматически генерируется и доступна по адресу:
`https://ваш-сайт.ru/sitemap.xml`

Для использования XML карты в поисковых системах добавьте в файл `robots.txt`:
`Sitemap: https://ваш-сайт.ru/sitemap.xml`

== Frequently Asked Questions ==

= Как добавить карту сайта на свой сайт? =
Используйте шорткод `[html_sitemap]` на любой странице или записи. Рекомендуем создать отдельную страницу "Карта сайта".

= Где найти XML карту сайта? =
XML карта доступна по адресу `https://ваш-сайт.ru/sitemap.xml`. Убедитесь, что XML карта включена в настройках плагина.

= Можно ли настроить внешний вид HTML карты? =
Да! Плагин использует CSS классы для легкой кастомизации. Смотрите раздел "Styling".

= Как исключить определенные страницы из карты сайта? =
В настройках плагина в разделе "Управление по ID" укажите ID страниц через запятую в поле "Исключить записи/страницы".
